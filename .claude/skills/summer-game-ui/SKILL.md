# summer-game-ui

夏休みゲームの UI/UX を作るときの決まりごと。目標は「仮素材のプロトタイプでも、UI に触れた瞬間に静かで懐かしい夏の雰囲気が伝わること」。
設計書 `DESIGN.md` の「12. UI/UX の方針」を具体的な値に落としたもの。**値に迷ったらこのファイルが正**。

## 1. 基本の考え方

- **静か・やさしい・手ざわり**：紙、木、ブリキ缶のような素朴な質感。強い原色、ネオン、光る縁取り、激しい揺れは使わない
- **ゲーム画面の邪魔をしない**：常に出すのは日付の札だけ。他は必要なときだけ出す
- **急に切り替えない**：表示・非表示・画面遷移には必ずフェードかゆるい動きをつける（ただし下の時間を超えて待たせない）
- **待たせない**：演出中でも決定キーやタップで早送り・スキップできる
- **PC とスマホの両方で気持ちよく**：キーボードでもタッチでも、すべての画面を迷わず操作できる。どちらかで使えない操作を作らない

## 2. 配色

`res://ui/ui_tokens.gd` に定数として定義し、`Theme` もこの値で作る。ノードに色を直接書かない。

| トークン | 色 | 用途 |
| --- | --- | --- |
| `PAPER` | `#F6EEDC` | パネルの地（古い紙） |
| `PAPER_DARK` | `#E8DCC0` | パネル内の枠、未取得の枠 |
| `INK` | `#3B3226` | 本文の文字 |
| `INK_SOFT` | `#7A6E5D` | 補足の文字、無効な項目 |
| `TIN` | `#B9C4C9` | 宝箱の缶の色 |
| `ACCENT` | `#D9763F` | 選択中の項目、強調（夕焼けのオレンジ）。1画面に1か所程度 |
| `SKY` | `#8EC5E0` | 日付の札の上部など、夏らしさの差し色 |
| `SHADE` | `#000000`（不透明度 45%） | 一時停止・宝箱を開いたときの背景の暗さ |
| `TIN_DARK` | `#9AA7AD` | 缶のふち・ふた |
| `FADE` | `#14110D` | 画面遷移・日の切り替わりの暗転（真っ黒より少しあたたかい） |
| `SHADOW` | `#000000`（不透明度 20%） | パネルの弱い影 |

- 文字と地のコントラストは十分に取る（`INK` on `PAPER` を基本にする）
- 夜の時間帯でも UI の色は変えない（UI は `CanvasModulate` の影響を受けない `CanvasLayer` に置く）

## 3. フォント

- 丸みのあるやさしい日本語フォントを `res://ui/theme/fonts/` に同梱する
  - 候補：Zen Maru Gothic、M PLUS Rounded 1c（どちらも SIL Open Font License）
  - ライセンスファイルもフォントと同じフォルダに置く
- フォントは `Theme` のデフォルトフォントに設定し、個別ノードで指定しない
- 文字サイズ（画面 1280×720 基準）

| 用途 | サイズ |
| --- | --- |
| 本文・一言・メニュー項目 | 24px |
| 補足・キー表示 | 18px（これより小さくしない） |
| 見出し（宝箱の名前など） | 32px |
| タイトル・日の切り替わりの大きな日付 | 48〜64px |

- 行間はゆったり（行の高さはサイズの 1.6 倍程度）
- 文章はひらがな多めで短く。1行は全角20文字程度まで

## 4. 形と余白

- 余白・配置は 8px 単位（8 / 16 / 24 / 32）
- パネル：角丸 12px、枠線 2px（`PAPER_DARK`）、内側の余白 24px
- 影はつけるなら弱く短く（ずらし 2〜4px、不透明度 20% 程度）。グラデーションの多用はしない
- 画面端から UI までは最低 **40px** あける（スマホの切り欠きや角の丸みに隠れないため）
- UI はアンカーで画面の端や中央に固定する。ストレッチのアスペクトは `expand` なので、画面の縦横比が変わってもはみ出さない配置にする（固定座標で置かない）

### タッチで押せる大きさ
- タップできる部分（ボタン・メニュー項目・宝箱の枠・「ひろう」の吹き出し）は、**最低 72×72px**（基準画面 1280×720 で。スマホの実寸でおよそ指先の大きさ）
- 見た目が小さいアイコンでも、押せる範囲は 72px 以上に広げる
- 押せる部分どうしは 16px 以上離す
- 画面の右上に置くボタン（宝箱・一時停止）は、歩くための「画面右半分の押し続け」と重ならないよう、ボタンを押した入力は歩く処理に渡さない

## 5. 動き（アニメーション）

すべて `Tween` で作り、トランジションは `TRANS_SINE`（または `TRANS_QUAD`）、イージングは表示が `EASE_OUT`、非表示が `EASE_IN`。跳ねる動き（`TRANS_BACK` / `TRANS_ELASTIC`）は使わない。

| 演出 | 時間 |
| --- | --- |
| 小さな表示の出入り（キー表示など） | 0.2 秒、少し上へ浮きながらフェード |
| パネルの開閉（一言・メニュー） | 0.25 秒、フェード＋わずかな拡大（0.96→1.0） |
| 宝箱のふたが開く | 0.4 秒 |
| 画面遷移のフェード | 0.4 秒 |
| 日の切り替わり（暗転→日付→明ける） | 合計 2.0 秒前後。決定キーで短縮できる |
| 日付の札がめくれる | 0.3 秒 |
| 一言の文字送り | 1文字 0.04 秒。決定キーで全文表示、もう一度で閉じる |
| エンディングのアイテムの出現 | 1つ 0.3 秒、間隔 0.15 秒 |
| 押した瞬間の沈み | 0.08 秒 |
| タイトルの「はじめる」案内の明滅 | 片道 1.2 秒でゆっくり |
| 一言パネルが自動で閉じるまで | 全文表示から 6 秒（キー／タップでもすぐ閉じられる） |

- 早送りは Tween の速さを 6 倍にする（`SKIP_SPEED`）

- 時間の値は `ui_tokens.gd` の定数を使い、数値を直接書かない
- `main_theme.tres` は `tools/build_theme.gd` が `ui_tokens.gd` から作る。値を変えたら `godot --headless --script res://tools/build_theme.gd` を実行し直す

## 6. 操作（UX）

### 共通
- キーボードだけでも、タッチだけでも、全画面を操作できること。マウスでも主要な操作はできること
- 入力は必ず入力アクション（`move_right`、`interact`、`ui_accept` など）を通す。タッチ用のコードは入力アクションを発生させるだけにし、ゲームやUIのコードはタッチかどうかを気にしない
- `ui_cancel`（Esc／タッチでは「もどる」ボタン）で必ず1つ前に戻れる
- ゲームが止まる画面（宝箱・一時停止）は `get_tree().paused = true` にし、その UI のノードは `process_mode = PROCESS_MODE_ALWAYS` にする
- 止まっている間も、背景のゲーム画面は `SHADE` で暗くして残す。**ぼかしシェーダーは使わない**（スマホのブラウザで重いため）
- ホバー（マウスを重ねる）でしか出ない情報を作らない

### キーボード
- メニューやグリッドは `focus_neighbor_*` を設定し、矢印キーで迷わず移動できるようにする。キーボードで操作を始めたら最初の項目に `grab_focus()` する
- 選択中の項目は `ACCENT` の色＋小さな印（例：左に「●」）で示す。色だけに頼らない

### タッチ
- タップしたらその項目を即決定する（「選んでからもう一度押す」にしない）。宝箱の枠はタップで詳細を表示する
- 押した瞬間に見た目が反応する（少し沈む・色が濃くなる、0.08 秒程度）
- タッチ操作中はフォーカスの印を出さない。キーボード入力が来たら印を出す
- 宝箱・一時停止などの画面には、タッチ用に左上か右上へ「もどる」ボタンを置く（Esc が押せないため）
- タッチ用のボタン（宝箱・一時停止）は、最初のタッチ入力で表示し、キーボード入力が来たら隠す
- 長押し・スワイプ・2本指操作など、気づきにくい操作には頼らない（歩くための「押し続け」は例外。最初に案内する）

## 7. 効果音

オートロード `SfxPlayer` を通して鳴らす。音素材がなくてもエラーにならないこと（無音で通る）。
ブラウザでは最初のタップ／クリック／キー入力まで音が鳴らせないので、タイトル画面の「はじめる」操作より前に音を前提にした演出を置かない。

| 呼び出し名 | 鳴らす場面 |
| --- | --- |
| `cursor` | カーソル移動 |
| `accept` | 決定 |
| `cancel` | 戻る |
| `pickup` | アイテムを拾う |
| `box_open` / `box_close` | 宝箱の開閉 |
| `day_change` | 日の切り替わり |
| `text_tick` | 文字送り（数文字おきに小さく） |

## 8. 実装の決まり

- UI は `CanvasLayer` の下に置き、ゲームの世界と分ける
- 共通の部品はシーン化して使い回す（例：`ui/components/paper_panel.tscn`、`menu_item.tscn`）
- `Theme` に入れられるものは `Theme` で設定する（`theme_override_*` は最小限）
- 画面遷移はオートロード `Transition` を通す（`Transition.change_scene(path)` など）。`change_scene_to_file` を直接呼ばない
- 文言は1か所にまとめる（`ui/strings.gd` など）。あとで調整しやすくするため。キーボードとタッチで文言が変わるもの（「E」と「ひろう」など）も両方ここに置く
- レンダラーは Compatibility。UI に使うシェーダーは軽いものだけにし、画面全体にかけるエフェクトは避ける

## 9. 作業後の確認

UI に手を入れたら、次を確認してから終える。

- [ ] 色・フォント・時間をノードに直接書いていない
- [ ] 日本語が欠けずに表示される
- [ ] 出入りが急に切り替わっていない
- [ ] キーボードだけで操作でき、Esc で戻れる
- [ ] タッチだけで操作でき、「もどる」ボタンで戻れる
- [ ] タップできる部分が 72px 以上あり、画面端から 40px 以上離れている
- [ ] 縦横比を変えても（例：1280×720 と 2340×1080 相当）UI がはみ出さない
- [ ] 演出を決定キーやタップで早送りできる
- [ ] 効果音の呼び出しが入っている
- [ ] 夜の時間帯でも UI の色が変わらない
