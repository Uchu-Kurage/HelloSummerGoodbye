# summer-game-ui

夏休みゲームの UI/UX を作るときの決まりごと。目標は「仮素材のプロトタイプでも、UI に触れた瞬間に静かで懐かしい夏の雰囲気が伝わること」。
設計書 `DESIGN.md` の「12. UI/UX の方針」を具体的な値に落としたもの。**値に迷ったらこのファイルが正**。

## 1. 基本の考え方

- **静か・やさしい・手ざわり**：紙、木、ブリキ缶のような素朴な質感。強い原色、ネオン、光る縁取り、激しい揺れは使わない
- **ゲーム画面の邪魔をしない**：常に出すのは日付の札だけ。他は必要なときだけ出す
- **急に切り替えない**：表示・非表示・画面遷移には必ずフェードかゆるい動きをつける（ただし下の時間を超えて待たせない）
- **待たせない**：演出中でも決定キーやタップで早送り・スキップできる
- **PC とスマホの両方で気持ちよく**：キーボードでもタッチでも、すべての画面を迷わず操作できる。どちらかで使えない操作を作らない

## 2. 配色

`res://ui/ui_tokens.gd` に定数として定義し、`Theme` もこの値で作る。ノードに色を直接書かない。

| トークン | 色 | 用途 |
| --- | --- | --- |
| `PAPER` | `#F6EEDC` | パネルの地（古い紙） |
| `PAPER_DARK` | `#E8DCC0` | パネル内の枠、未取得の枠 |
| `INK` | `#3B3226` | 本文の文字 |
| `INK_SOFT` | `#655A4B` | 補足の文字、無効な項目（紙の上で 5.8:1、濃い紙の上で 5.0:1） |
| `TIN` | `#B9C4C9` | 宝箱の缶の色 |
| `ACCENT` | `#D9763F` | 夕焼けのオレンジ。紙の上では 2.8:1 しかないので、文字・印・選択の枠には使わない（飾りだけ） |
| `ACCENT_INK` | `#9C4A1F` | 選択中の項目の文字・「●」・選択の枠（濃い夕焼け色。紙の上で 5.3:1）。1画面に1か所程度 |
| `SKY` | `#8EC5E0` | 日付の札のとじ側の下の細い線など、夏らしさの差し色（ゲームの空と同じ色なので、面で塗らず線で使う） |
| `SHADE` | `#000000`（不透明度 45%） | 一時停止・宝箱を開いたときの背景の暗さ |
| `TIN_DARK` | `#9AA7AD` | 缶のふち・ふた |
| `FADE` | `#14110D` | 画面遷移・日の切り替わりの暗転（真っ黒より少しあたたかい） |
| `SHADOW` | `#000000`（不透明度 20%） | パネルの弱い影 |

- 文字と地のコントラストは **4.5:1 以上**（大きな文字・図形は 3:1 以上）。`INK` on `PAPER` を基本にする
- 空・缶・道など、紙以外の上に置く文字は `INK_SOFT` では足りないので `INK` を使う。景色の上に置くメニューには紙の小札（`PaperChip`）を敷く
- 夜の時間帯でも UI の色は変えない（UI は `CanvasModulate` の影響を受けない `CanvasLayer` に置く）

## 3. フォント

- 丸みのあるやさしい日本語フォントを `res://ui/theme/fonts/` に同梱する
  - 候補：Zen Maru Gothic、M PLUS Rounded 1c（どちらも SIL Open Font License）
  - ライセンスファイルもフォントと同じフォルダに置く
- フォントは `Theme` のデフォルトフォントに設定し、個別ノードで指定しない
- 文字サイズ（画面 1280×720 基準）

| 用途 | サイズ |
| --- | --- |
| 本文・一言・メニュー項目 | 24px |
| 補足・キー表示 | 18px（これより小さくしない） |
| 見出し（宝箱の名前など） | 32px |
| タイトル・日の切り替わりの大きな日付・日付の札の数字 | 48〜64px |

- 行間はゆったり（行の高さはサイズの 1.6 倍程度）
- 文章はひらがな多めで短く。1行は全角20文字程度まで

## 4. 形と余白

- 余白・配置は 8px 単位（8 / 16 / 24 / 32）
- パネル：角丸 12px、枠線 2px（`PAPER_DARK`）、内側の余白 24px
- パネルより小さい部品（宝箱の枠・看板・缶の敷き紙）は角丸 6px（`SMALL_RADIUS`）。全部を同じ角丸・同じ影のカードにしない
- 宝箱の缶はふちを太く（`TIN_RIM` 6px、`TIN_DARK`）。空の枠は缶のくぼみ（缶より少し暗い地、上だけ濃い線）、拾ったものは紙の上に置く
- 影は浮いている UI（パネル・吹き出し・日付の札）だけ。世界の中の看板には付けない
- 影はつけるなら弱く短く（ずらし 2〜4px、不透明度 20% 程度）。グラデーションの多用はしない
- 画面端から UI までは最低 **40px** あける（スマホの切り欠きや角の丸みに隠れないため）
- **小さい画面**（短い辺が CSS で 520px 未満。スマホ横向き）では基準の大きさを 1280×720 から 1024×576 に切り替える（オートロード `DisplayPrefs`）。基準 18px の文字が実寸 12px 以上、本文 24px が 16px 以上、72px のボタンが 44pt 以上になるようにするため。UI は 1024×576 でもはみ出さないこと（宝箱は列の数を画面の幅で 3〜5 列に変える）
- カメラは画面の下端を地面（y=720）にそろえる。縦が狭い画面では空のほうを切る
- 一言パネルは画面の右寄り（左端は画面の幅の 44%）に置き、左寄りにいるプレイヤーを隠さない
- UI はアンカーで画面の端や中央に固定する。ストレッチのアスペクトは `expand` なので、画面の縦横比が変わってもはみ出さない配置にする（固定座標で置かない）

### タッチで押せる大きさ
- タップできる部分（ボタン・メニュー項目・宝箱の枠・「ひろう」の吹き出し）は、**最低 72×72px**（基準画面 1280×720 で。スマホの実寸でおよそ指先の大きさ）
- 見た目が小さいアイコンでも、押せる範囲は 72px 以上に広げる
- 押せる部分どうしは 16px 以上離す
- 画面の右上に置くボタン（宝箱・一時停止）は、歩くための「画面右半分の押し続け」と重ならないよう、ボタンを押した入力は歩く処理に渡さない

### 部品の形（題材から）
- **日付の札**：日めくり。とじ側の帯は `PAPER_DARK` に、とじ穴（`INK_SOFT` の小さな丸）を2つ。下に `SKY` の細い線。日付の数字を主役にする
- **一言パネル**：ノートの罫線（`PAPER_DARK`、行の高さにそろえる）の上に文字を書く。拾ったときは画面の右下、NPC との会話のときは画面の上（日付の札と右上のボタンのあいだ）に出し、話している人を隠さない
- **会話の選択肢**：一言パネルの下の段に、横に並べる（`ChoiceItem`。紙の小札にうすい枠、選択中は `ACCENT_INK` の文字と「●」）。せりふを送るつもりの連打で選ばないよう、出てから 0.3 秒は決定を受けつけない
- **ミニゲーム（秘密基地づくり）**：専用の寄りの画面（背景は雨の景色）。左に盤、右に紙のパネルのトレー（ピースの枠 88×88、`ChoiceItem`、5列×3行。使ったピースの枠は空けたまま残し、盤が動かないようにする）。持っているピースは `ACCENT_INK` の枠と「●」、盤の上では影（材料の絵を半分すかし、`ACCENT_INK` のふち）で置ける場所を示す。キーボードのカーソルは `ACCENT_INK` の太い枠。上にタケルのひとことの小札、盤の下に「いまできること」の小札、トレーの下に「まわす」「もどす」。会話のパネルはミニゲームのあいだ隠す。操作はタップが基本で、ドラッグは近道（ドラッグだけにしない）
- **ミニゲーム（石切り）**：専用の画面（昼の川原。パネルは置かない）。足もとの石は下に横並びの `ChoiceItem`（144×100、石の絵と名前。キーボードで選んでいる石は `ACCENT_INK` の枠と「●」）。上にタケルのひとことの小札、下に案内の小札（石を選ぶとき：タッチ「なげる いしを タップ」／キーボード「やじるしで いしを えらんで けってい」、かまえるとき：タッチ「がめんを おしつづけて…」／キーボード「Space を おしつづけて…」）。かまえているあいだ、タッチでは右上に「えらびなおす」（このボタンの上は押しつづけに数えない）、キーボードは Esc。ゲージは出さず、腕の位置と「きゅっ」の音で伝える。跳ねている石は決定キー／タップで早送り。動きを減らす設定では、水面の光とカメラの追いかけを止める
- **ミニゲーム（型抜き）**：専用の画面（夜の屋台の台の上。パネルは置かない）。型は画面のまん中に大きく、となりにタケルの型を小さく。上にタケル・屋台のおじさんのひとことの小札、下に押しつづけの案内の小札（タッチ「がめんを おしつづけて けずる…」／キーボード「Space を おしつづけて けずる…」）。ひびはゲージにせず、型の線と音とふるえで伝える。いま削る部分は `ACCENT` のうすい縁どり（飾り）と `ACCENT_INK` の小さな「●」。右上のボタンは隠す。結果の演出は決定キー／タップで早送りできる。動きを減らす設定では、手元のふるえを止める
- **ミニゲーム（カブトムシとり）**：専用の画面（早朝の暗く青い林。パネルは置かない）。上にタケルの小声の小札（`SmallLabel` の 18px・`INK_SOFT`。数秒で消える）、下に押しつづけの案内の小札（タッチ「がめんを おしつづけて そーっと すすむ…」／キーボード「Space を おしつづけて そーっと すすむ…」）。手が届いたら、案内の上に「つかむ」（`ChoiceItemSelected`、180×72）を出し、案内は「「つかむ」を タップ」／「Space で つかむ」にかえる。画面のどこをタップしても、つかめる。右上のボタンは隠す。つかんだあとは決定キー／タップで早送り。動きを減らす設定では、しのび足の上下のゆれを止める
- **ミニゲーム（タイムカプセル埋め）**：専用の画面（夜の基地の床。パネルは置かない）。懐中電灯の丸い光の中だけを見せる（画面を暗くする重ね絵に丸い穴。Light2D は使わない）。場所は下に横並びの `ChoiceItem`（144×72、「ひだり／まんなか／みぎ」。キーボードで選んでいる場所は `ACCENT_INK` の枠と「●」、光もその場所へ動く）。上にタケル（と主人公）のひとことの小札、下に案内の小札（段階ごとに、タッチ「タップで ひとすくい ほる」など／キーボード「Space で ひとすくい ほる」など）。右上のボタンは隠す。星の場面は決定キー／タップで早送り。動きを減らす設定では、光のゆれを止める
- **ミニゲーム（帽子を受け止める）**：専用の画面（バスの窓から後ろを振り返った景色。パネルは置かない）。エンディングの直前なので案内は最小限：下の小札に、いまの操作だけ（タッチ「おしつづけて まどを あける」「とんでくる ぼうしを タップ」「タップで てを ふる」／キーボードは「Space を…」「ぼうしが ちかづいたら Space」）。帽子は直接タップ（押せる範囲は半径 80px、近づくとうすい輪で示す）。上にタケルと主人公のひとことの小札。右上のボタンは隠す。振り返るところとカーブのあとは決定キー／タップで早送り。動きを減らす設定では、窓のガタつき・帽子の回転とゆれ・流れる景色・手をふる動きを止める
- **ミニゲーム（飛び込み）**：専用の画面（景色を主役にし、パネルは置かない）。上にタケルのかけ声の小札、下に押しつづけの案内の小札（`SmallLabel`、タッチ「がめんを おしつづけて…」／キーボード「Space を おしつづけて…」）を控えめに出す。画面のどこを押してもよいので、右上のボタンは隠す。跳んだあとの演出は決定キー／タップで早送りできる。動きを減らす設定では、足のふるえ・光のゆれ・泡・波を止める
- **初恋ルート（なつみ）の画面**：どれも `NatsumiScreen` を継承（パネルは置かない）。上になつみのひとことの小札（`PaperChip`、「なつみ「……」」）、下にいまの操作の案内の小札（`SmallLabel`）。右上のボタンは隠す。結果の演出は決定キー／タップで早送り
  - スケッチ：左に見本、右に画用紙。選択肢は下に横並びの `ChoiceItem`（144×100、色の見本か形の絵。キーボードで選んでいるものは `ACCENT_INK` の枠と「●」）。案内はタッチ「いろや かたちを タップで えらぶ」／キーボード「やじるしで えらんで けってい」
  - 金魚すくい：水槽を上から見る。画面のどこをタップしても（Space でも）すくう。すくった数は水槽の右下の紙の小札
  - 貝がら拾い：貝がらは下に横並びの `ChoiceItem`（128×96、貝がらの絵だけ。名前は出さない。白い貝がらは紙の上で見えるようにふちを描く）。波が寄せているあいだは押せない
  - 線香花火：始める前に、押しつづけの案内を必ず出す（タッチ「がめんを おしつづけて…（おすと はじまるよ）」／キーボード「Space を おしつづけて…」）。燃えているあいだは「はなさないでね」。動きを減らす設定では、風のゆれ・手のぶれ・火花の動きを止める
  - 映画会：画面は暗いまま、上の小札に音を書く（「（ギィ……）」など）。タップで早送り
  - 絵を広げる：紙が左から右へ広がる（動きを減らす設定では、すぐ全部見せる）。広げ終わったら「タップで とじる」／「Space で とじる」
- **神隠しルート（お面の子）の画面**：どれも `NatsumiScreen` を継承（パネルは置かない）。上にお面の子のひとことの小札（「おめんの子「……」」。せりふでない音や様子は「（……いない）」のように括弧で）、下にいまの操作の案内の小札。右上のボタンは隠す。結果の演出は決定キー／タップで早送り
  - かくれんぼ：調べるところは下に横並びの `ChoiceItem`（176×168、絵と名前）。調べたところはうすく暗くし、「（……いない）」の小札でも伝える（色だけにたよらない）。案内はタッチ「かくれていそうな ところを タップ」／キーボード「やじるしで えらんで けってい」
  - 夜市の物々交換：店は下に横並びの `ChoiceItem`（208×150。店の人・ほしいもの → くれるもの の絵）。その上に「てもと：〇〇」の紙の小札
  - 鈴の音で道探し：「ひだり」「みぎ」の `ChoiceItem`（200×96）。鈴の音と同時に、鳴ったほうで小さな光がゆれる（音が出せない環境でも進める）。動きを減らす設定では光をゆらさない
  - 鬼ごっこ：押しつづけの案内（タッチ「がめんを おしつづけて はしる」／キーボード「Space を おしつづけて はしる」）
  - 鈴を振る：タップ（Space）で振る。鳴ったあと「タップで とじる」。動きを減らす設定では鈴をゆらさない
- **日付の札の「？？」**：異界の日（神隠しルート）は月と日を「？？」にする（`Strings.DATE_UNKNOWN`）。めくれ方はふだんと同じ。時間が飛ぶところ（10日目）は、暗転のなかで大きな日付が1枚 `TIME_DATE_RIFFLE`（0.1 秒）前後でぱらぱらめくれる（はじめと終わりは少しゆっくり。決定キー／タップで早送り）
- **手ばなしたものの枠**（人にあげた・うめた）：缶のくぼみのまま、名前とひとこと（「タケルに あげた」「うめた」）を `OnTinSmallLabel` で出す。絵は出さない
- **吹き出し**：近づいたものに合わせて文言を変える（アイテムは「E」／「ひろう」、NPC は「E」／「はなす」）。一言パネルを出している間は出さない
- **タイトル**：パネルを置かず景色を主役にする。題字（To The Summer）は右上に横書きで右寄せ（添え書きは置かない）。案内とメニューは下の道の帯の上に置く。1画面で一番目立つのはこの題字だけ

## 5. 動き（アニメーション）

すべて `Tween` で作り、トランジションは `TRANS_SINE`（または `TRANS_QUAD`）、イージングは表示が `EASE_OUT`、非表示が `EASE_IN`。跳ねる動き（`TRANS_BACK` / `TRANS_ELASTIC`）は使わない。

| 演出 | 時間 |
| --- | --- |
| 小さな表示の出入り（キー表示など） | 0.2 秒、少し上へ浮きながらフェード |
| パネルの開閉（一言・メニュー） | 0.25 秒、フェード＋わずかな拡大（0.96→1.0） |
| 宝箱のふたが開く | 0.4 秒 |
| 画面遷移のフェード | 0.4 秒 |
| 日の切り替わり（暗転→日付→明ける） | 合計 2.0 秒前後。決定キーで短縮できる |
| 日付の札がめくれる | 0.3 秒 |
| 日付がぱらぱらめくれる（神隠しルートの10日目） | 1枚 0.1 秒前後 |
| 一言の文字送り | 1文字 0.04 秒。決定キーで全文表示、もう一度で閉じる |
| エンディングのアイテムの出現 | 1つ 0.3 秒、間隔 0.15 秒 |
| 押した瞬間の沈み | 0.08 秒 |
| タイトルの「はじめる」案内の明滅 | 片道 1.2 秒でゆっくり |
| 一言パネルが自動で閉じるまで | 全文表示から 6 秒（キー／タップでもすぐ閉じられる）。会話は自動で閉じず、読み終えるまで待つ |

- 早送りは Tween の速さを 6 倍にする（`SKIP_SPEED`）
- **閉じる動きは開く動きの約 7 割**（パネル 0.18 秒、小さな表示 0.14 秒、宝箱のふた 0.16 秒）。すばやく反応させる。画面遷移のフェードは行き帰りとも 0.4 秒
- **動きを減らす設定**（ブラウザの prefers-reduced-motion）が有効なら：拡大・浮き上がり・ふたの持ち上げはやめてフェードだけにする。雲を流さない、アイテムをゆらさない、タイトルの案内を明滅させない、日付の札はめくらずにフェードで入れかえる（`UiAnim.reduced()` で判定）。夏の空気（光の粒・光の筋）は動かさず、手前の木の枝と風鈴はゆらさない

- 時間の値は `ui_tokens.gd` の定数を使い、数値を直接書かない
- `main_theme.tres` は `tools/build_theme.gd` が `ui_tokens.gd` から作る。値を変えたら `godot --headless --script res://tools/build_theme.gd` を実行し直す

## 6. 操作（UX）

### 共通
- キーボードだけでも、タッチだけでも、全画面を操作できること。マウスでも主要な操作はできること
- 入力は必ず入力アクション（`move_right`、`interact`、`ui_accept` など）を通す。タッチ用のコードは入力アクションを発生させるだけにし、ゲームやUIのコードはタッチかどうかを気にしない
- `ui_cancel`（Esc／タッチでは「もどる」ボタン）で必ず1つ前に戻れる
- ゲームが止まる画面（宝箱・一時停止）は `get_tree().paused = true` にし、その UI のノードは `process_mode = PROCESS_MODE_ALWAYS` にする
- 止まっている間も、背景のゲーム画面は `SHADE` で暗くして残す。**ぼかしシェーダーは使わない**（スマホのブラウザで重いため）
- ホバー（マウスを重ねる）でしか出ない情報を作らない

### キーボード
- メニューやグリッドは `focus_neighbor_*` を設定し、矢印キーで迷わず移動できるようにする。キーボードで操作を始めたら最初の項目に `grab_focus()` する
- 選択中の項目は `ACCENT` の色＋小さな印（例：左に「●」）で示す。色だけに頼らない

### タッチ
- タップしたらその項目を即決定する（「選んでからもう一度押す」にしない）。宝箱の枠はタップで詳細を表示する
- 押した瞬間に見た目が反応する（少し沈む・色が濃くなる、0.08 秒程度）
- タッチ操作中はフォーカスの印を出さない。キーボード入力が来たら印を出す
- 宝箱・一時停止などの画面には、タッチ用に左上か右上へ「もどる」ボタンを置く（Esc が押せないため）
- タッチ用のボタン（宝箱・一時停止）は、最初のタッチ入力で表示し、キーボード入力が来たら隠す
- 長押し・スワイプ・2本指操作など、気づきにくい操作には頼らない（歩くための「押し続け」は例外。最初に案内する。押しつづけると少しして走りだすが、走らなくても遊べるおまけなので案内はしない）

## 7. 効果音

オートロード `SfxPlayer` を通して鳴らす。音素材がなくてもエラーにならないこと（無音で通る）。
ブラウザでは最初のタップ／クリック／キー入力まで音が鳴らせないので、タイトル画面の「はじめる」操作より前に音を前提にした演出を置かない。

- 音素材は `audio/sfx/`・`audio/ambient/`・`audio/music/` に `<呼び出し名>.ogg` で置く。CC0 など再配布できるものだけを使い、`CREDITS.md` に出典を書く
- 環境音（`set_ambient`）と BGM（`play_music`）はくり返し鳴り、切り替えはクロスフェード。BGM はタイトルとエンディングだけ（本編は環境音だけで夏を伝える）

| 呼び出し名 | 鳴らす場面 |
| --- | --- |
| `cursor` | カーソル移動 |
| `accept` | 決定 |
| `cancel` | 戻る |
| `fanfare` | アイテムを手に入れる（拾う・もらう）。主人公の前にアイテムの絵が浮かび上がる（`ItemFanfare`） |
| `pickup` | 宝箱にアイテムが並ぶ |
| `furin` | 家の軒先の風鈴。風が吹いたとき、主人公が近くにいれば鳴る（遠いほど小さく） |
| `box_open` / `box_close` | 宝箱の開閉 |
| `day_change` | 日の切り替わり |
| `text_tick` | 文字送り（数文字おきに小さく） |

## 8. 実装の決まり

- UI は `CanvasLayer` の下に置き、ゲームの世界と分ける
- 共通の部品はシーン化して使い回す（例：`ui/components/paper_panel.tscn`、`menu_item.tscn`）
- `Theme` に入れられるものは `Theme` で設定する（`theme_override_*` は最小限）
- 画面遷移はオートロード `Transition` を通す（`Transition.change_scene(path)` など）。`change_scene_to_file` を直接呼ばない
- 文言は1か所にまとめる（`ui/strings.gd` など）。あとで調整しやすくするため。キーボードとタッチで文言が変わるもの（「E」と「ひろう」など）も両方ここに置く
- レンダラーは Compatibility。UI に使うシェーダーは軽いものだけにし、画面全体にかけるエフェクトは避ける

## 9. 作業後の確認

UI に手を入れたら、次を確認してから終える。

- [ ] 色・フォント・時間をノードに直接書いていない
- [ ] 日本語が欠けずに表示される
- [ ] 出入りが急に切り替わっていない
- [ ] キーボードだけで操作でき、Esc で戻れる
- [ ] タッチだけで操作でき、「もどる」ボタンで戻れる
- [ ] タップできる部分が 72px 以上あり、画面端から 40px 以上離れている
- [ ] 縦横比を変えても（例：1280×720 と 2340×1080 相当）UI がはみ出さない
- [ ] 演出を決定キーやタップで早送りできる
- [ ] 効果音の呼び出しが入っている
- [ ] 夜の時間帯でも UI の色が変わらない
- [ ] 文字と地のコントラストが 4.5:1 以上ある（景色の上の文字も）
- [ ] 1024×576 の基準（スマホ横向き）でもはみ出さない
- [ ] 動きを減らす設定で、拡大や流れる動きが止まる
