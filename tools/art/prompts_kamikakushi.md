# 神隠しルート（お面の子）の絵のプロンプト

いま図形や SVG で描いている仮の絵を、ほかの場面と同じ水彩の絵（Google Gemini）に差し替えるためのプロンプト。
コードの枠（```text）の中を、そのままコピーして Gemini に貼る（共通の約束は付けてある）。
できた絵は `tools/art/process_painted.py` で切り抜いて `world/scenery/painted/<名前>.png` に置く（ミニゲームの背景は `ui/minigame_bg/<名前>.jpg`）。

仮の絵がどこにあるか：

| 仮の絵 | 場所 | 差し替えるところ |
| --- | --- | --- |
| お面の子（お面あり・なし） | `world/scenery/kamikakushi/fox_child.svg`・`fox_child_face.svg` | `data/npcs/fox_*.tres` の `sprite`（お面なしは `fox_shrine.tres` の `alt_sprite`）、`world/fox_far.gd`・`ui/kakurenbo_game.gd`・`ui/onigokko_game.gd` の `FOX_TEX` |
| 祠・灯籠・狛犬・大木・夜市の屋台・店の人・青い提灯・ひまわり | `world/kamikakushi_prop.gd`（図形で描いている） | 種類ごとの描く関数を、`scenery_prop.gd` の `_art()` と同じように絵を描くものにかえる |
| ミニゲームの背景 | 各画面の `_draw()`（図形で描いている） | `MinigameBg.draw_cover()` で絵を敷く（`ui/kaigara_game.gd` と同じ） |
| アイテム6つ | `data/items/icons/*.svg` | `data/items/<名前>.tres` の `icon` |

## 共通の約束（どのプロンプトにも、最後に付ける）

下のプロンプトには、この約束がもう付いている（そのままコピーして貼ればよい）。新しくプロンプトを書くときは、最後にこれを付ける。

**小物・人物（背景を切り抜くもの）**

```text
やわらかい透明水彩のイラスト。細い茶色の鉛筆の線を少し残し、にじみと紙の白を活かす。日本の田舎の昭和〜平成の夏。くすんだ緑・砂色・夕焼け色を基調に、強い原色や光る縁取りは使わない。真横から見た図（遠近をつけすぎない）。足もと（地面との境目）を絵の下のふちにそろえる。地面の影は描かない。背景は完全に均一なマゼンタ（#FF00FF）一色で、グラデーション・紙の質感・影を背景に入れない。文字や看板の字は入れない。
```

**ミニゲームの背景（全面の絵）**

```text
やわらかい透明水彩のイラスト。細い茶色の鉛筆の線を少し残す。日本の田舎の夏。横長（およそ 2.4:1）。人物は描かない。画面の上のほうと下のまん中は、文字の札を重ねるので、ごちゃごちゃさせない。文字は入れない。
```

**神隠しルートの絵の決まり**（「こわい雰囲気にしない。静かで、さみしくて、少しふしぎ。」の一文は、下のプロンプトに付けてある）

- こわい話にしない。**静かで、さみしくて、少しふしぎ**。おばけ・血・暗すぎる影・目の光る顔は描かない
- 異界（夜市・7日目の煙のむこう・8〜9日目）の絵も、**ふつうの色で描く**。色はゲームの中で抜く（`OtherworldZone`）。灰色に塗った絵にしない
- 青い提灯・あおいほおずき・あおい あめだまの「青」は、くすんだ水色〜藍色（`#7FA8D8` くらい）。ネオンのような青にしない
- 人物はほかの立ち絵と同じ 4 頭身くらいの子ども。**右向き**（ゲームの中で左右を反転して使う）
- お面の子：小学 4 年生くらいの男の子。**何十年も前の夏の子ども**なので、服は少し古い。短く刈った黒い髪、色あせた藍色の甚平（白い細かいかすり模様。前を脇のひもで結ぶ上着と、ひざ丈の半ズボン。何度も洗って、やわらかくなった木綿）、わらぞうり。日に焼けすぎていない、色白の肌
- きつねのお面：白地に、朱色のくまどり（目のまわりと耳の内側）、細く笑った目、ひたいに朱色の丸い宝珠、黒い鼻と口。**どの絵でも同じデザインにする**（アイテム `fox_mask` の絵とも合わせる）
- 鈴：手のひらに乗るくらいの、丸い真鍮の鈴。茶色いさびがまだらに出て、色あせた赤いひもがついている（アイテム `rusty_bell` の絵と合わせる）
- ぼく：白地に紺のボーダーのTシャツ、ベージュの半ズボン、水色の帽子（`player_1.png` と同じ）
