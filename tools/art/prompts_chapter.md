# 章「あの夏へ」（老年期・破・急）の絵のプロンプト

章「あの夏へ」で、いま図形やカードで描いている仮の絵を、序と同じ水彩の絵（Google Gemini）に差し替えるためのプロンプト。
コードの枠（```text）の中を、そのままコピーして Gemini に貼る（共通の約束は付けてある）。
できた絵は `tools/art/process_painted.py` で切り抜いて置く。章の名前（`elder`・`youth`・`photo_*`・`bg_hospital` など）は、まだ `process_painted.py` の `SPLITS`／`BACKGROUNDS` に入っていないので、絵ができたら足す（コードへのつなぎ込みも、そのとき行う）。

いまの状態：

| 絵 | 状態 | 使っているところ |
| --- | --- | --- |
| 老人のぼく・青年のぼく | 子どものぼく（`player_1〜5`）を大きくして色を変えたもの | `player/player.gd` の `FORM_SCALE`・`FORM_TINT` |
| 老人のなつみ・青年のなつみ・看護師・工事の人 | 図形の人（`NpcData` の色だけ） | `data/npcs/chapter_*.tres` |
| 病室・家・今の村・造成地の小物 | 図形（`world/chapter_art.gd` の `ChapterArt.Kind`） | `days/chapter/*.tscn` |
| 遠くの山のてっぺん | 図形の三角（鳥居は `prop_torii` を使っている） | `world/torii_peak_view.gd` |
| 写真 23 枚 | 色の四角に場所の名前を書いたカード | `data/photos/*.tres` の `picture`（`ui/components/photo_card.gd`） |
| 急の病室（写真を見せる場面） | 図形の部屋と人 | `ui/hospital_finale.gd` の `_draw_art` |
| 使い捨てカメラ・缶の封筒 | 色の四角 | `data/chapter/items_chapter_camera.tres`、`ui/can_open.gd` |

もう絵があるので描かなくてよいもの：鳥居・祖父母の家・縁側・精霊馬・座敷と親戚・送り火・バス停・駄菓子屋・タケルの家・秘密基地の材料・川の飛び込み岩・祖父母・タケル・子どものなつみ・お面の子・子どものぼく・さびた鈴。

## 共通の約束（どのプロンプトにも、最後に付ける）

下のプロンプトには、この約束がもう付いている（そのままコピーして貼ればよい）。新しくプロンプトを書くときは、最後にこれを付ける。

**小物・人物（背景を切り抜くもの）**

```text
やわらかい透明水彩のイラスト。細い茶色の鉛筆の線を少し残し、にじみと紙の白を活かす。日本の田舎の昭和〜平成の夏。くすんだ緑・砂色・夕焼け色を基調に、強い原色や光る縁取りは使わない。真横から見た図（遠近をつけすぎない）。足もと（地面との境目）を絵の下のふちにそろえる。地面の影は描かない。背景は完全に均一なマゼンタ（#FF00FF）一色で、グラデーション・紙の質感・影を背景に入れない。文字や看板の字は入れない。
```

**写真（全面の絵）**

```text
やわらかい透明水彩のイラスト。細い茶色の鉛筆の線を少し残す。使い捨てカメラで撮った昭和の夏のスナップ写真のような構図（少し傾いていたり、端が切れていたりしてよい。ピントはやわらかく）。正方形に近い 4:3 の横長。ふちどり・白い枠・日付の文字は描かない（ゲームの中で写真のふちを付ける）。文字は入れない。
```

**章の絵の決まり**

- 章のテーマは「あの夏は一度しか来ない」。**静かで、なつかしくて、さみしい。でも、あたたかい**。大げさな表情や、こわい雰囲気にしない
- 人物は序の立ち絵と同じ 4 頭身くらい。**右向き**（ゲームの中で左右を反転して使う）
- 老年期は「今」（令和のころ）。村は変わってしまっている（新しい家・造成地）。**神社と鳥居と山だけは変わらない**
- 青年期は、あの夏から十数年後（平成のはじめごろ）。回想なので少し温かい色
- 破の写真は、老人の心が子どもの体で撮った、**あの夏（昭和）のお盆の4日間**。タケルが撮った写真には、タケル自身は写らない
- 子どものぼく：白地に紺のボーダーのTシャツ、ベージュの半ズボン、水色の帽子（`player_1.png` と同じ）
- タケル：日に焼けた、つんつんした短い黒髪の男の子。白いランニングシャツ、紺の半ズボン、ゴムのサンダル（`npc_takeru.png` と同じ）
- なつみ・祖父母・お面の子は、それぞれ `npc_*.png` と同じ見た目
