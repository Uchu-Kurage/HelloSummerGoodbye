# ひと夏のタイムライン（正史）

Oct 9, 2026 · @Ryoga

## 考え方（正史の決まり）

序の4つのルートは、プレイヤーにはルートごとに遊んでもらうが、物語の正史では**すべてがひと夏に起きた**ことにする。老年期・破・急はこの正史を前提にする。

- ルートごとに日付をずらし、1日に1つのルートの出来事を基本にする
- まだルートが決まっていない日（7/21・7/23・7/24・8/1）は、複数の子が出てくる
- 一度しかない行事のうち、夏祭り（8/6）は一晩に全員、帰る日（8/31）は全員の見送りが重なる
- 8/13〜8/16（お盆）は、神隠しルートの子どもの魂が異界にいた期間。そのあいだ子どもの体で過ごしていたのは、未来から来た老人の心（破）。だから序の他のルートには、この4日間の出来事がない
- 初恋ルートは、高エンドを正史とする（なつみが宿題の絵をくれる）
- タケルはこの夏のあとの冬、引っ越しの前に交通事故で亡くなる

## 8/31 帰る日の順番

各ルートのエンディングは、この一続きの場面の一部を切り出したもの。

1. バス停。祖父母の見送り。「からだに きをつけてな」「おにぎり、バスで たべなさいね」
2. 祖父が鈴ときつねのお面に気づき、少し黙る。「……なつかしいな」
3. 祖父「らいねんも、まってるからな」
4. なつみが走ってきて、宿題の絵をくれる。「……もう いっかい かくから」
5. バスに乗る。動き出す
6. 自転車のタケルが坂を追いかけてきて、窓から帽子を投げ入れる。「やくそくだぞー！」
7. バスがカーブを曲がる。鈴が一度だけ鳴る
8. おにぎりの包みを開く。少しだけ、しょっぱい

## その後の年表

| その年の冬 | 引っ越しの前に、タケルが交通事故で亡くなる |

| 青年期（その後の夏） | なつみの初めての小さな展覧会。夏祭りの夜、神社の石段で線香花火、プロポーズ |
| 老年期 | なつみが認知症になり、入院している。祖父母の家は空き家。秘密基地の雑木林は造成地になっている |
| 老年期の 8/12 | 病室でなつみを見舞う。家で思い出の品を探すが、何も残っていない。さびた鈴だけが見つかる |
| 老年期の 8/13 | 村を訪れる（迎え火）。神社でお面の子と再会し、あの夏の 8/13 へ（破） |
| 老年期の 8/16 以降 | 現代に戻る（急）。造成地の工事で缶が見つかる |

- タイムカプセルの本当の場所を知っていたのはタケルだけ。9日目の地図の一言「バツじるしが ずれてる きがする。」は、その伏線
