# 老年期・破・急 シナリオ（初稿）

Oct 9, 2026 · @Ryoga

## 概要

作品全体のテーマは「あの夏は一度しか来ない」。序で子どもの夏を体験してもらい、破・急で、その夏が二度と戻らないことを痛感してもらう。

| 部 | 時期 | 内容 |
| --- | --- | --- |
| 序 | 子どもの夏 | 4つのルート（ノーマル・親友・初恋・神隠し）。正史ではすべてがひと夏に起きた |
| 老年期の導入 | 老年期の 8/12〜8/13 | 認知症のなつみのために、あの夏の思い出を探す。何も残っていない。変わった村で、青年期のなつみとの思い出を振り返る |
| 破 | 子どもの夏の 8/13〜8/16 | 神隠しで子どもの魂が異界にいたお盆の4日間を、老人の心が子どもの体で過ごす。カメラであの夏を撮る |
| 急 | 老年期の 8/16 以降 | 現代に戻る。カメラは持ち帰れない。破で知った場所を頼りに造成地で缶を掘り当てる。缶の奥底に、タケルの手紙と現像された写真 |

**章の名前と入り方**

- 老年期の導入・破・急をまとめて、章「あの夏へ」とする
- 序の4つのエンディングをすべて見ると、4つ目のエンディングのスタッフロールのあと、予告なしにそのまま始まる（暗転 → 章題「あの夏へ」→ 病室）。主人公があの夏へ戻る瞬間に、タイトルコール「To The Summer」を出す
- 見たエンディングの記録（`user://`）は、この判定に使う

**変えられない、という方針**

戻っても、あの夏は変えられない。破で老人の心がしたことは、最初からそうなっていたことになる（家族が神隠しに気づかなかったのは、老人の心が代わりに過ごしていたから）。

**登場人物（老年期）**

- 主人公：老人。一人称は「ぼく」のまま。心の声は（　）で書く
- なつみ：主人公の妻。認知症で入院している。主人公のことは分からない。時々「あおい えんぴつ」「そらを ぬらなきゃ」と、あの夏のかけらを口にする
- タケル：あの夏のあとの冬に亡くなっている
- お面の子：異界の住人。年をとらない

**登場人物（青年期の回想）**

- 青年の主人公、青年のなつみ（画家を目指している）。タケルは出てこない

**表記の決まり**

- 章「あの夏へ」（老年期・青年期の回想・破・急）のせりふと心の声は、漢字まじりの、ふつうの大人の文章にする（序はひらがな多めのまま）
- 破で出てくる子どもや祖父母も、口調は序と同じ子どもらしさ・年寄りらしさのまま、表記だけ漢字まじりにする（老人の目で見ているため）
- 例外：子どもが書いた字（タケルの手紙、宿題の絵の題「なつやすみの おもいで」など）は、ひらがなのまま
- 序と同じ言葉を、表記だけ変えて出す場面がある（「きょうは、なにしたの？」→「今日は、何したの？」、鈴の「ふっても ならない。」→「振っても鳴らない。」）。同じ言葉が大人の字になることで、時間がたったことを見せる

## 老年期の導入

**遊び方の決まり**

- 序と同じ横スクロール。老人の主人公は**ダッシュできない**（歩く速さは同じ）
- 青年期の回想では青年の主人公を操作し、ダッシュできる。破で子どもの体に戻ると、またダッシュできる。急ではまた走れなくなる
- 序の宝箱の代わりに、「ポケット」の画面。中身は鈴だけ

| 場面 | 遊び方 |
| --- | --- |
| 病室（8/12 夕方） | 病院の廊下 → 病室の短い横スクロール。調べられるのは、なつみ（会話）、りんご（むいて、なつみの前に置く）、窓（夕焼けの空）。会話の最後の「……今日は、何したの？」は選択肢ではなく、自動で言う |
| 家（8/12 夜） | 家の中を右へ歩き、押し入れ・本棚・たんすを調べる。たんすで鈴を見つけると、「……あの村に、行ってみるか」で暗転し、翌朝の村へ |
| 村（8/13 朝〜夕方） | 右へ歩くと、場所ごとに「今 → 子どものころが一瞬重なる → 青年期」に切り替わる。時間帯はバス停の朝から、神社の夕方（迎え火が灯るころ）まで進む |

**青年期の回想で遊ぶこと**

| 場所 | 遊び方 |
| --- | --- |
| バス停 | ベンチのなつみに歩み寄って話す（再会） |
| 田んぼ道 | 夕焼けの道を、なつみと並んで歩く。なつみが指さした空を見上げる |
| 雑木林 | タケルの地図を頼りに3か所を掘る。どこを掘っても見つからない（急で缶が出てくるときに効く空振り） |
| 公民館 | 展覧会の絵を順に見ていく。最後が、子どものころの宿題の絵 |
| 神社 | 二人で線香花火。ミニゲームではなく演出で、今度は火の玉が最後まで落ちない（子どものころは自分のが先に落ちた）。そのあと、プロポーズ |

### 0. 章題（病室の前）

4つ目のエンディングのスタッフロールが終わると、画面は暗いまま。蝉の声も止んでいる。

黒い画面の真ん中に、章題がゆっくり浮かぶ。

> あの夏へ

- 序の日付の札と同じ紙の質感。文字は大きい日付と同じくらい（48〜64px）
- フェードイン → 静止 → フェードアウトで合3秒ほど。決定で早送りできる
- 消えると、病院の廊下の音（遠くの足音、空調の音）が小さく始まり、病室の場面へ

### 1. 病室（8/12・夕方）

窓辺のベッドに、なつみ。主人公はりんごをむいている。

> なつみ「……どちら様？」 ぼく「お見舞いに来たんだよ」 なつみ「そう。……青い鉛筆、知らない？」 なつみ「空を塗らなきゃ」 ぼく「……今日は、何したの？」

なつみは首をかしげて、窓の外を見る。

> 看護師「ご主人、今日もありがとうございます」

（あの夏の物があれば、何か思い出すかもしれない）

- 「きょうは、なにしたの？」は、序の縁側の場面で祖母が毎晩言っていた言葉。ここで初めて主人公が言う側になる。同じ言葉が、大人の字（漢字まじり）で出る

### 2. 家（夜）

押し入れ、本棚、たんすを調べる。

- アルバムの箱：からっぽ。（引っ越しのときに、なくしたんだったな）
- 本棚：なつみの絵は一枚も残っていない
- 祖父母の家から引き取った古いたんすの奥：さびた鈴。振っても鳴らない。説明は序の1日目と同じ言葉を漢字で「振っても鳴らない。」

（何も残ってない） （……あの村に、行ってみるか）

### 3. 村（8/13）

右へ歩く。各場所で「今 → 子どものころが一瞬重なる → 青年期の思い出 → 今に戻る」の順に見せる。

**バス停**

今：新しい待合所。祠だけが残っている。 重なる：祖父母が待っていたバス停。 青年期（二十歳の夏）：

> なつみ「……久しぶり。覚えてる？」 ぼく「……なつみ？」 なつみ「町で、絵の勉強してるの」 なつみ「夏休みだけ、帰ってきた」

**田んぼ道**

今：住宅地。 重なる：あぜで絵を描く、子どものなつみ。 青年期：

> なつみ「まだ、青い鉛筆で空を塗ってるの」 ぼく「あのときの？」 なつみ「まさか。……でも、同じ色」 なつみ「この色じゃないと、だめなの」

（今は、屋根ばかりだ）

**雑木林**

今：造成地のフェンス。「立入禁止」。 重なる：板とトタンの秘密基地。 青年期（8/31）：なつみと二人で、タケルの地図を頼りにタイムカプセルを掘る。見つからない。

> なつみ「……ないね」 ぼく「タケルの地図、下手くそだったからな」 なつみ「タケルくんの分も、いつか見つけようね」

（結局、見つけてやれなかった）

**公民館**

今：建て替えた建物。掲示板には体操教室の貼り紙。 重なる：ラジオ体操の朝。 青年期：なつみの初めての小さな展覧会。子どものころの宿題の絵「なつやすみの おもいで」も飾られている。

> なつみ「小さい展覧会だけど」 なつみ「これ、君にあげた絵の、もう一枚」 なつみ「約束したでしょ。もう一回描くって」

（あの絵も、もうどこにもない）

**神社**

今：ここだけ変わっていない。家々の門口に、ぽつぽつと迎え火。 青年期（夏祭りの夜）：石段で二人で線香花火。

> なつみ「今度は、最後まで落ちなかったね」 ぼく「なつみ。……結婚しよう」

なつみは何も言わずにうなずく。

回想が終わると、同じ石段に老人の主人公が一人。

（……もう、あの夏はどこにもないのか）

ポケットの鈴が、何十年ぶりに鳴る。石段の上に、きつねのお面の子。

> お面の子「……久しぶり」 「大きくなったね。……違うか。年をとったね」 「あの夏に、もう一度連れてってあげる」 「でも、何も変えられないよ」 「持って帰れるのは、心だけ」 「送り火までね」

鈴が鳴り、景色が白くなる。

**タイトルコール**

白い画面に、鈴の音の余韻だけが残る。そこへ、遠くから蝉の声が戻ってくる。

> To The Summer

- ゲームのタイトルロゴとして、画面いっぱいに大きく出す。章題「あの夏へ」の英語で、ここで初めて、この作品の名前が出る
- 序では一度も聞こえなかった、破だけの音楽をここで始める（音素材が入るまでは蝉の声だけ）
- 白からロゴが浮かび、少し止まり、そのまま夜の迎え火の森へ溶けていく。合わせて5秒ほど。決定で早送りできる
- 破の最初の場面（8/13 の夜、迎え火の森の入口で目を覚ます）へ続く

## 破：お盆の4日間（8/13〜8/16）

神隠しルートで、お面の子が子どもの魂を異界へ連れていったお盆の4日間。そのあいだ、空になった子どもの体で、老人の心が過ごす。家族が神隠しに気づかなかったのは、このため。

**決まり**

- 体は子ども、心は老人。主人公のせりふは子どもらしい口調で、心の声（　）は老人。表記はどちらも漢字まじり
- 何も変えられない。誰にも、本当のことは言えない
- 期限は 8/16 の送り火。子どもの魂が戻ると、老人の心は現代へ帰る

**カメラ（遊び）**

- 祖母が、お盆に親戚が集まるので買っておいた使い捨てカメラ
- 村のあちこちに「写真のポイント」がある。ポイントでシャッターを切ると、その場面の写真のアイテムが手に入る（写真の絵は別途用意）
- 写真は現像しないと見られない。破のあいだは「げんぞう まえの しゃしん」としてしか持てず、中身を確かめられるのは、急でタイムカプセルを開けてから
- フィルムの枚数には限りがあり、撮り直しはできない。どのポイントで撮るかはプレイヤーが選ぶ
- タケルがカメラを取り上げて撮る写真もある（決まった場面）

**写真のポイント（15か所、フィルム12枚）**

ポイントはフィルムより多いので、少なくとも3か所は撮れずに終わる。カメラは 8/13 の夜、茶の間のたんすで見つける。

| 日 | ポイント |

| 8/13 夜 | 1. 迎え火を焚く祖父　2. 縁側の精霊馬　3. 座敷で酒盛りをする親戚 |
| 8/14 | 4. 駄菓子屋のおばちゃん　5. タケルの家の前の段ボール箱　6. 秘密基地とタケル　7. 川の飛び込み岩 |
| 8/15 | 8. 田んぼ道で絵を描くなつみ　9. なつみの描きかけの絵（青い空）　10. 公民館の掲示板　11. 神社の鳥居 |
| 8/16 | 12. 縁側でスイカを切る祖母　13. 祖父母の家の外観　14. バス停　15. 送り火を囲む家族 |

**タケルが破のあいだに撮る写真（決まった場面、12枚とは別）**

- 8/14：タケルが腕を伸ばして撮る、二人の写真
- 8/14：主人公の後ろ姿
- 8/15：田んぼ道の青空。自転車で通りかかったタケルが撮る（急の病室で、なつみの反応のよりどころになる）

**残したフィルム（タケルが使う）**

プレイヤーが12枚を使い切らなかった場合、老人の心が帰ったあと、残りをタケルが使う。残りの枚数だけ、上から順に撮られる（最大5枚。それより残った分は、何も写っていない真っ黒な写真になる）。

1. 8/18：飛び込み岩から飛ぶ、少年の主人公（しぶき）
2. 8/24：なつみ。タケル「あいつに みせて やる」と言って撮った、田んぼ道のなつみ
3. 8/19：映画会の帰り、ならんで歩く主人公となつみの後ろ姿
4. 8/23：タイムカプセルを埋める主人公の手（夜、懐中電灯）
5. 8/31：坂の上から撮った、走り去るバス

- 残したフィルムが多いほど、老人の心が見られなかった夏の続きが届く。全部撮れば、あの4日間がすべて残る
- 序では写らなかったタケルの目線なので、写真にタケル自身は写らない
- 描く写真は、ポイント15枚＋破のタケル3枚＋残りのタケル5枚の計23枚

**カメラの画面（序の宝箱の代わり）**

- 時代が違うので、破では序の宝箱は使わず、別の画面にする
- フィルムの残りと、「げんぞう まえの しゃしん」の一覧を見る。一覧には日付と場所だけが出て、絵は出ない

**遊び方の決まり**

- 子どもの体なので、ダッシュできる
- 写真のポイントの前に立つと「とる」が出る（序の「ひろう」と同じ出し方）。撮ると心の声が一言出る。フィルムがなくなると「フィルムが ない」
- 日の終わりの縁側の場面は形を変える。アイテムの代わりにカメラを見せると、祖母が聞く。8/13〜8/15 の3晩だけ、8/16 は送り火でそのまま帰る

> おばあちゃん「何を撮ったの？」 ぼく「……忘れたくないもの」

毎晩の縁側の言葉は、日ごとに少し変える。

- 8/13：おばあちゃん「何を撮ったの？」 ぼく「……忘れたくないもの」
- 8/14：おじいちゃん「フィルム、大事に使えよ。現像も高いんだ」
- 8/15：おばあちゃん「明日は送り火だねえ。……みんな、帰っちゃうね」（老人の心が帰る日のことでもある）

### 8/13 迎え火

夜、迎え火の森の入口で目を覚ます。子どもの体。お面の子の姿はもうない。

（……本当に、戻ったのか）

灯りをたどって祖父母の家へ帰ると、座敷には親戚、縁側には精霊馬。

> おばあちゃん「どこ行ってたの。心配したのよ」

**カメラを見つける**

座敷から、親戚の笑い声。玄関を上がると、老人の心がふと思い出す。

（そうだ。あの夏、ばあちゃんはカメラを買っていた） （誰も使わないまま、たんすにしまわれていたはずだ）

茶の間のたんすを調べる。老年期の家で鈴を見つけたのと同じたんす（のちに主人公が引き取るもの）。上の引き出しは裁縫道具、真ん中は手紙の束。一番下の引き出しに、箱に入ったままの使い捨てカメラ。

（あった……）

うしろから祖母がのぞきこむ。

> おばあちゃん「あら、それ。みんなで撮ろうと思って買ったのに、誰も使わないのよ」 「使っていいよ。好きなもの、撮りなさい」 ぼく「……うん。ありがとう」

（これで、なつみに見せてやれる）

カメラを手にすると、画面の隅に「のこり 12」が出る。ここから写真のポイントで撮れるようになる（座敷の親戚、縁側の精霊馬、迎え火の祖父）。

- 老年期の家ではたんすを探しても鈴しかなかった。同じたんすを、今度はあの夏の姿で探す。対になる場面

夜、縁側で祖父と並ぶ。老人の心にとって、祖父は今の自分と同じくらいの年。

> おじいちゃん「お盆になると、思い出すやつがいてな」 「子どもの頃、いなくなっちまった友達だ」 ぼく「……きっと、待ってると思うよ」

（その友達は今、ぼくの代わりに、あの子と遊んでいる）

### 8/14 タケル

朝、カメラを首から下げて村へ出る。

駄菓子屋の前で、おばちゃんが序の2日目と同じ言葉を言う。子どものころは聞き流した一言を、今度は意味が分かったうえで聞く。

> おばちゃん「タケルちゃんと、遊んであげてね」 「あの子も、寂しくなるからねえ」

村を歩いて撮る。タケルの家の前に、段ボール箱が積んである。タケルが出てくる。

> タケル「何撮ってんだよ」 ぼく「……いろいろ」 タケル「なんでそんなに撮るんだよ」 ぼく「……忘れたくないから」 タケル「変なやつ」

一緒に村を歩くうちに、気づけばタケルばかり撮っている。

（この子は、この冬に……）

> タケル「おまえも写れよ。貸して」

秘密基地で、タケルが腕を伸ばして二人の写真を撮る。川では、前を歩く主人公の後ろ姿も勝手に撮る（どちらもタケルが撮る決まった写真で、12枚とは別）。

**タケルの「秘密の場所」**

写真を撮ったあと、タケルが基地の裏へ手まねきする。

> タケル「いいもん見せてやる。ここ立ってみ」 「……鳥居と、山のてっぺん。重なって見えるだろ」 ぼく「……ほんとだ」 タケル「おれの秘密の場所。大事なもんは、ここに埋めるって決めてんだ」 「だれにも言うなよ」

（……ここだったのか） （タケルの地図は、最初からずれていたんだ）

- 序の 8/23、タイムカプセルはこの場所に埋められる。タケルが描いた地図のバツじるしは、子どもの描いた地図なのでずれていた。本当の場所を知っていたのはタケルだけ
- 「鳥居と山のてっぺんが重なる」は、横スクロールの背景のずれ（遠くの山はゆっくり、近くの鳥居は速く動く）を使う。二つが重なって見える位置は、道の上で一か所だけ
- 鳥居のある神社と山は、老年期になっても変わらない。だから急でもこの印で場所が分かる

> タケル「おまえ、来年も来んのか？」 ぼく「……うん」

### 8/15 なつみ（盆の中日）

田んぼ道で、なつみが宿題の絵を描けずにいる。

> なつみ「夏休みの思い出って、何描けばいいのかな」 「……大人になったら、忘れちゃう？」 ぼく「忘れないよ」 「……なつみが忘れても、ぼくが覚えてる」

なつみは少し笑って、青い色えんぴつで空を塗り始める。

> なつみ「写真より、絵のほうがいいと思うけど」 「……まあ、いいよ。撮って」

そこへ、タケルが自転車で通りかかる。主人公の手からカメラを取り上げ、空に向ける。

> タケル「いい空だぞ。撮ってやる」 「……よし。じゃあな」

タケルはそのまま走り去る。

- 破で、なつみとタケルが同じ場面にいるのはここだけ。三人がそろう短い一瞬
- この青空の写真が、急の病室でなつみの反応のよりどころになる

### 8/16 送り火

昼、最後の村を歩いて撮る。フィルムの残りが少なくなっていく。

縁側で、祖母がスイカを切っている。

> おばあちゃん「スイカ、冷えてるよ。食べなさい」

（この人の「食べなさい」を、何十年ぶりに聞いた）

夕方、家族と送り火を焚く。煙のむこうに、お面の子。

> お面の子「時間だよ」

最後に、隣の祖父を見上げる。

> ぼく「……おじいちゃん、ありがとう」 おじいちゃん「なんだ、いきなり」

主人公はカメラを握りしめる。

> ぼく「……これだけ、持っていけない？」 お面の子「言ったでしょ。心だけ」

煙が白くなる。カメラは、子どもの手の中に残る。

## 急：現代に戻る

### 1. 神社（老年期の 8/16・夜）

石段で目を覚ます。手の中には何もない。鈴にはひびが入り、もう鳴らない。

- ダッシュを押しても走れない。操作で、老人に戻ったことが伝わる
- ポケットの鈴の説明は「もう鳴らない。」に変わる
- 石段を下りて、暗転。翌朝へ

（……やっぱり、持って帰れなかった） （あの夏は、写真にも残せないのか）

### 2. 造成地（翌日）

造成地のフェンスの前。秘密基地のあった雑木林は、もうない。工事の人に頼んで、中へ入れてもらう。

> 工事の人「昭和の宝物、ですか」 「ここ、来月には道路になるんですよ。……どうぞ、少しだけなら」

スコップを借りて、むき出しの土の上を歩く。木も基地もなく、地図は役に立たない。遠くに、変わらない神社の鳥居と、山のてっぺん。

（鳥居と、山のてっぺんが重なるところ）

- 歩くと、背景のずれで鳥居と山のてっぺんの位置が少しずつ近づく。重なった場所で「ほる」が出る
- 重なっていない場所でも掘れるが、何も出てこない（青年期の空振りと同じ）
- 重なった場所で掘ると、決定を数回押して掘り進め、スコップの先に硬いものが当たる
- 破で秘密の場所を教わっているので、必ずたどり着ける。教わっていないという分かれはない

（……あった）

さびた缶。ふたを開ける。ビー玉と、9日目に自分が入れた宝物（プレイヤーが序の親友ルートで実際に選んだもの。選んだアイテムは \`user://\` に記録しておく）。

（……タケル。見つけたよ）

写真はない。缶を閉じかけたとき、奥底にビニールに包まれた封筒があることに気づく。

中には、現像された写真の束と、タケルの手紙。手紙は子どもの字なので、ひらがなのまま。

> おまえ、おぼんの とき、へんだったよな。 ずっと おれの こと みてた。 しゃしん、おまえの すきな ものばっかり だった。 だから、ここに いれとく。 じいさんに なった おまえへ。 なつみと、けっこん したか？

残したフィルムをタケルが使った場合だけ、手紙に一行加わる。

> のこりは おれが とった。 なつみのやつは、おまけだ。

写真は日付順に並ぶ。破でプレイヤーが撮ったものとタケルが破で撮った写真（手紙にくるまれた二人の写真をのぞく）、そのあとに、残りのフィルムでタケルが撮ったもの（あれば）。

**缶を開ける画面（遊び方）**

1. ふたを開けると、中身が1つずつ出てくる。ビー玉と、親友ルートで選んだ宝物（説明は序の一言のまま。子どものころの言葉なので、ひらがな）
2. 「缶の底を調べる」で、ビニールに包まれた封筒が出てくる
3. タケルの手紙。紙の上に、子どもの字（ひらがな）で一行ずつ出る。手紙には写真が1枚だけくるまれている（タケルが破で撮った二人の写真。裏に「おれと おまえ」）。この1枚は、ここでは裏しか見られず、表を見るのは病室でなつみと一緒
4. 写真の束を1枚ずつめくる。写真の下に日付と、老人の心の声が出る。真っ黒な写真は（……何も写っていない。それでも、捨てられない）

- 最初に写真を見るのは、プレイヤーと主人公だけ
- ここから、ポケットの画面で写真をいつでも見られる

### 3. 病室

写真の束を、日付順に1枚ずつなつみに見せていく（決定で次の写真）。なつみは写真に合わせて短く反応する。束を見終えたあと、**最後に、手紙にくるまれていた二人の写真**を見せる。この1枚がキーになる。

| 見せた写真 | なつみの反応 |
| --- | --- |
| 祖父・祖母・親戚 | 「……優しそうな人たちね」 |
| タケル | 「……元気な子」 |
| なつみ・なつみの絵・空 | 「……きれいな青」 |
| 村の景色 | 「……いいところね」 |
| 真っ黒な写真 | （なつみは黙って、指で写真の表をなでる） |
| 少年の主人公（後ろ姿） | 「……誰かしら」 |
| 少年の主人公（飛び込み・映画会の帰り） | 「……この子、知ってる気がする」 |

少年の主人公が写っている写真はどれもタケルが撮ったもの。束の中では「誰かしら」「知ってる気がする」と少しずつ近づき、最後の1枚で思い出す。主人公は自分を撮れないので、少年のころの主人公を写したのはタケルだけ。タケルが「おれと おまえ」と書いて別にしておいた写真が、なつみに主人公を思い出させる。

最後の1枚（二人の写真）を見せる。

> なつみ「……この子」 「……青い鉛筆、拾ってくれた子」

なつみが、隣に座る主人公の顔を見る。

> なつみ「……あなた」 ぼく「……うん」 なつみ「……今日は、何したの？」 ぼく「……あの夏に、行ってきたよ」 なつみ「……そう」

なつみは小さく笑う。

- 序の1日目、田んぼ道で色えんぴつを拾った出会いを、なつみが思い出す
- 「今日は、何したの？」を、最後はなつみが主人公に聞く。序の縁側で祖母が聞いていたように

* なつみの記憶は治らない。主人公が誰かも分からないまま。それでも、一瞬だけあの夏が届く
* 撮らなかったポイントの写真は出ない

- キーの写真は破でタケルが必ず撮るので、どんな撮り方をしても、最後には必ずクライマックスにたどり着く
- 束の枚数はプレイヤーの撮り方で変わるが、最後の1枚は変わらない

### 4. 空を見上げる

なつみが窓の外の空を見上げる（青空の写真と同じような青）。主人公も、隣で同じ空を見上げる。画面がゆっくり白くなる。

### 5. エンディング

スタッフロールとともに、序の子どもの夏の思い出が流れる。タケル、なつみ、お面の子、祖父母と遊んだ場面（秘密基地、夏祭り、川、線香花火、縁側など）。みんなで遊んだ、二度と来ない夏。

- 絵は新しく描かず、序の背景と、破の写真の絵を使い回す
- 撮らなかったポイントの写真の絵も、ここで初めて流れる。撮れなかった夏も、ちゃんとあった
